# NER Landslide Watch Prototype

A lightweight React + Vite prototype for an AI-based early warning and landslide risk monitoring system tailored for the North Eastern Region (NER).

## Features
- Real-time hazard dashboard
- Risk mapping for NER states
- Alert severity tracking
- AI-driven landslide monitoring concept page

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```
